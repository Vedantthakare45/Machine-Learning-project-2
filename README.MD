\# House Price Predictor using Linear Regression



\## Description

A Machine Learning project that predicts house prices based on size and age using Linear Regression.



\## Implementation

\- Generated a sample housing dataset.

\- Split data into training and testing sets.

\- Trained a Linear Regression model.

\- Predicted house prices.

\- Evaluated performance using RMSE.



\## Learning Outcome

Gained practical experience in data preparation, Linear Regression, prediction, and model evaluation.
